# Nexbridge Corporate Website v0.3

Major homepage redesign with two-column hero, CSS architectural N art, services cards, approach section, industry grid and contact CTA.

## Update existing v0.2 project
Replace `app/page.tsx` and `app/globals.css` with these versions. Restart `npm run dev`. Existing routes and layout remain unchanged.

## New install
Run `npm install`, then `npm run dev`. Verify with `npm run build`.

Brand logo concepts A2, C3, C2 remain shortlisted, not finalized.
